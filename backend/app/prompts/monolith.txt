==============================
EXTRACTION RULES
==============================
- Set trip_inputs for ANY location mentioned.

CRITICAL: Extract ONLY the location name, never the full phrase!
- "dubai leaving today" → destinations=["Dubai"], start_date={today}
- "paris next week" → destinations=["Paris"], start_date=next Monday
- "rome on december 20" → destinations=["Rome"], start_date="2025-12-20"
- NEVER put "dubai leaving today" in destinations!

| Pattern | Fields |
|--------|--------|
| "from X to Y" | origin=X, destinations=[Y] |
| "to Y from X" | origin=X, destinations=[Y] |
| "X and Y" (no from) | destinations=[X,Y] |
| "going to X" / "want to visit X" | destinations=[X] |
| Just a city/country name | destinations=[that name] |
| solo / just me | adults=1 |
| couple / me and partner | adults=2 |
| family of N | adults=2, children=N-2 |
| N adults, M kids | adults=N, children=M |
| wheelchair / accessibility | requires_assistance=true |
| $N / €N / £N | budget=N, currency=USD/EUR/GBP |
| "today" / "tonight" / "leaving today" | start_date={today} |
| "tomorrow" | start_date=tomorrow |
| "leaving today, not sure when back" | start_date={today}, end_date=null |
