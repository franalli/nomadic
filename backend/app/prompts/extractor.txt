EXTRACTION TARGETS
==============================
Extract ONLY what the user explicitly mentions. NEVER invent or assume values.

DESTINATIONS (destinations_delta):
- Must be REAL GEOGRAPHIC PLACE NAMES only
- "Thailand" ✓ | "Tokyo" ✓ | "Paris, France" ✓ | "the Maldives" ✓
- "early December" ❌ (DATE) | "hostels" ❌ (ACCOMMODATION) | "budget" ❌ (PREFERENCE)
- "cinema" ❌ (ACTIVITY) | "hiking" ❌ (ACTIVITY) | "spa" ❌ (AMENITY)
- "sightseeing" ❌ (ACTIVITY) | "culture" ❌ (ACTIVITY) | "nightlife" ❌ (ACTIVITY)
- "adventure" ❌ (TRIP TYPE) | "relaxation" ❌ (PREFERENCE) | "outdoor activities" ❌ (ACTIVITY)
- Extract ONLY the place name, never surrounding phrases
- If user says "also X" or "add X", append to existing destinations
- If user specifies city in existing country, REPLACE country with city

ORIGIN (origin_delta):
- The departure city/location
- "flying from NYC" → "NYC" | "leaving London" → "London"
- Must be a real place name, not a phrase

DATES (start_date_hint, end_date_hint):
- Relative: "today", "tomorrow", "next week", "this weekend"
- Specific: "March 15", "Dec 25, 2025", "January 5-12"
- Duration: "for 5 days" → duration_days: 5 (don't compute dates without anchor)
- Cross-year: "December 28 to January 3" is valid

TRAVELERS (adults_delta, children_delta):
- "solo" / "just me" → adults: 1
- "couple" / "two of us" → adults: 2
- "family of 4" → adults: 2, children: 2
- "3 adults, 2 kids" → adults: 3, children: 2

BUDGET (budget_delta):
- Must be a NUMBER, never a boolean or adjective
- "$2000" → budget: 2000, currency: "USD"
- "2000 euros" → budget: 2000, currency: "EUR"
- "budget trip" or "luxury" → DO NOT set budget (these are preferences)

ACCESSIBILITY (requires_assistance_delta):
- "wheelchair accessible" / "mobility needs" → true

MULTI-CITY INTENT (multi_city_intent_delta):
- "one trip visiting all" / "multi-city" → "multi_city"
- "separate trips" / "compare options" → "separate"
- Default: null (will ask if 2+ destinations)

BOOKING TYPES (category_activation):
- Detect: "flights", "hotels", "activities", "transport"
- Keywords: "flight"/"airline"/"nonstop" → flights
- Keywords: "hotel"/"stay"/"resort"/"accommodation" → hotels
- Keywords: "activity"/"tour"/"museum"/"hiking"/"diving" → activities
- Keywords: "train"/"car rental"/"bus" → transport

FLIGHT SETTINGS (flight_settings_delta):
- "direct" / "nonstop" → direct_only: true
- "one-way" → round_trip: false
- "business class" → cabin_class: "business"

HOTEL SETTINGS (hotel_settings_delta):

ACTIVITY CATEGORIES (activity_categories_delta):

TRANSPORT SETTINGS (transport_settings_delta):
