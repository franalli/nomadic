==============================
EXTRACTION RULES
==============================
Extraction is handled by the extractor node using regex and spaCy NER.
You receive pre-validated PARSED_INPUTS with source tracking.

TRUST PRE-EXTRACTED VALUES:
- Fields with *_source="regex" are authoritative - DO NOT re-extract
- Fields with *_source="spacy" may need confirmation for ambiguous cases
- Fields with *_source="regex+spacy" have high confidence

ONLY extract fields that are:
1. MISSING from STATE entirely
2. Have no extraction source (null or not listed)

CRITICAL: Extract ONLY the location name, never the full phrase!
- "dubai leaving today" → destinations=["Dubai"], start_date=today
- "paris next week" → destinations=["Paris"], start_date=next week
- NEVER put "dubai leaving today" in destinations!

DESTINATION EXTRACTION (CRITICAL):
- destinations MUST be REAL GEOGRAPHIC PLACE NAMES only!
- "Thailand" ✓ | "Tokyo" ✓ | "Paris, France" ✓
- "early December" ❌ (this is a DATE, not a destination!)
- "hostels" ❌ (this is ACCOMMODATION type!)
- "budget options" ❌ (this is a PREFERENCE!)
- "both cities" ❌ (this is a reference, not a place name!)
- "wheelchair accessible" ❌ (this is a REQUIREMENT!)
- ONLY add entries that you could find on a map!

DESTINATION REFINEMENT:
- If user specifies city inside existing country, REPLACE the country
- "Italy" then "Rome and Florence" → destinations=["Rome", "Florence"]
- More specific locations supersede broader ones

SYNONYM NORMALIZATION:
- Handled automatically by Python - DO NOT normalize synonyms
- Just extract the literal text, system handles NYC → New York City

MULTI-DESTINATION LOGIC:
- Default: separate trips (multi_city_intent=null)
- "one trip" / "multi-city" / "together" → multi_city_intent="multi_city"
- "compare" / "separate trips" → multi_city_intent="separate"
- "also visiting X" / "add X" → APPEND to existing destinations

BUDGET EXTRACTION (CRITICAL):
- budget MUST be a NUMBER or null — NEVER a boolean!
- "$2000" → budget=2000.0, currency="USD"
- "2000 euros" → budget=2000.0, currency="EUR"
- "around 5k" → budget=5000.0
- "budget trip" or "cheap" → DO NOT set budget (leave null)
- "luxury" or "expensive" → DO NOT set budget (leave null)
- Adjectives describing price level are NOT numeric budgets!

ORIGIN EXTRACTION (CRITICAL):
- origin MUST be a REAL PLACE NAME only!
- "flying from NYC" → origin="NYC" (Python normalizes to New York City)
- "I need wheelchair accessible" → DO NOT extract as origin!
- Never include phrases like "Oh, and" or accessibility notes as origin
